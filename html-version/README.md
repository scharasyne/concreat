# Concreat Holdings Philippines - HTML/CSS/JavaScript Version

This is a pure HTML, CSS, and JavaScript conversion of the original React/TypeScript website for Concreat Holdings Philippines.

## 📁 Project Structure

```
html-version/
├── index.html          # Home page
├── about.html          # About Us page
├── academy.html        # Academy page
├── programs.html       # Public Programs page
├── newsroom.html       # Newsroom page (placeholder - needs to be created)
├── contact.html        # Contact page
├── css/
│   └── styles.css     # All styles
└── js/
    └── main.js        # JavaScript functionality
```

## 🚀 Features

- **Fully Responsive Design**: Works on mobile, tablet, and desktop
- **No Dependencies**: Pure vanilla HTML, CSS, and JavaScript
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Modern CSS**: Uses CSS custom properties (variables) for theming
- **Smooth Scrolling**: For anchor links
- **Form Handling**: Contact form with validation
- **SEO Friendly**: Semantic HTML structure

## 🎨 Design System

The design follows the original color scheme:

- **Primary**: DMCI Blue - `hsl(218, 99%, 31%)`
- **Secondary**: Mid Blue - `hsl(218, 55%, 50%)`
- **Charcoal**: `hsl(0, 0%, 22%)`
- **Silver**: `hsl(0, 0%, 75%)`
- **Sky Blue (Accent)**: `hsl(197, 73%, 73%)`

## 🔧 How to Use

1. **Open Locally**: 
   - Simply open any HTML file in a web browser
   - No build process or server required

2. **Deploy**:
   - Upload all files to any web hosting service
   - Ensure the folder structure is maintained
   - The site will work immediately

3. **Customize**:
   - Edit colors in `css/styles.css` (`:root` section)
   - Modify content directly in HTML files
   - Add JavaScript functionality in `js/main.js`

- CSS is organized with a mobile-first approach
- Form submission shows an alert (replace with actual backend integration)

## 🔄 Differences from React Version

- **No Routing**: Uses separate HTML files instead of React Router
- **No State Management**: Uses vanilla JavaScript for interactivity
- **Static Content**: All content is hard-coded in HTML
- **Simplified Icons**: Uses inline SVG instead of Lucide React icons
- **No Build Process**: Direct deployment without compilation
